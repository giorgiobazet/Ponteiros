# Simulador de Memória e Ponteiros em C

🔗 **Demo ao vivo:** https://giorgiobazet.github.io/Ponteiros/

Simulador interativo para visualizar como variáveis e ponteiros funcionam na memória, feito com HTML, CSS e JavaScript puro.

## Como usar

1. **Declare na memória:** crie variáveis `int` e ponteiros `int*` informando nome e valor
2. **Execute comandos em C:** digite instruções como `px = &x;`, `*px = 50;`, `y = *px;` ou `py = px;`
3. **Acompanhe a "Placa de Memória RAM":** veja endereços e valores mudando a cada comando, com o histórico no log

## Como executar

Abra o arquivo `index.html` em qualquer navegador moderno. Não precisa instalar nada.

## Objetivo

Ferramenta didática para entender endereços, referência (`&`) e desreferência (`*`), conceitos centrais de ponteiros na linguagem C.

## Tecnologias

HTML, CSS e JavaScript.
